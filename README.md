# SCLP — ручной маркет-мейкинг в QUIK (FORTS)

Скрипт QLua для торговли руками горячими клавишами: ↑/↓ выставляют **пассивные** заявки («Только пассивная», Book-or-Cancel) с заданным отступом от стакана. Скрипт двигает только закрывающие заявки и не хуже безубытка. Плюс тейк-профит, PANIC, метрики и восстановление после перезапуска.

Всё — в папке [`SCLP/`](SCLP/README.md): запуск, клавиши, метрики, устройство и план проверки.

```
SCLP/sclp.lua                 запустить в QUIK (Сервисы -> Lua скрипты)
SCLP/sclp_config.lua          настройки (счёт, комиссии, лимиты)
SCLP/lib/                     модули
SCLP/tools/probe_passive.lua  проверка «Только пассивная» у брокера - один раз перед боем
SCLP/tools/test_sclp.lua      тесты: lua SCLP/tools/test_sclp.lua (Lua 5.3/5.4, без QUIK)
SCLP/tools/sim_quik.lua       эмулятор QUIK и биржи для тестов
```
